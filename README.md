# med-tracker
Hosted locally via Docker, Med Tracker is an open source logger/viewer of any pro re nata medication

**Created by Andrew Cincotta, Financial Analyst.**


## Software Stack
**Composer**
- Docker
- Vite
- Uvicorn

**Backend**
- FastAPI
- SQLAlchemy
- Alembic

**Frontend**
- React.js
